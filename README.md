# 소풍 가는 길

갈림길을 골라 퍼즐을 풀며 언덕을 오르는 소풍 모험. 휴대폰 홈 화면에 설치해서 앱처럼 쓰는 웹앱이에요.

- 게임 원본: `dev/picnic-road.html` (파일 하나에 전부 들어 있어요)
- 다시 만들기: `pip install fonttools brotli` 후 `python3 dev/build.py`
- 저장소 맨 위의 `index.html`, `sw.js`, `manifest.webmanifest`, `fonts/`, `icons/`는 만들어진 결과물이고, GitHub Pages가 그대로 보여 줘요.
